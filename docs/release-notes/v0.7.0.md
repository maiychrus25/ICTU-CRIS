# ICTU-CRIS v0.7.0

> Phát hành 13/09/2026. Tag `v0.7.0`; ảnh `ghcr.io/maiychrus25/ictu-cris:0.7.0` và `:0.7.0-ai` (kèm thư viện AI).

Bản 0.7.0 sửa tận gốc khái niệm "đơn vị": các khoa thật của Trường được đọc từ bộ lọc `dept`
của kho nguồn, chức vụ (Hiệu trưởng, Trưởng khoa…) tách khỏi khoa; thêm bộ lọc điểm quy đổi và
loại nơi công bố; hồ sơ giảng viên đủ như kho nguồn (ảnh, lĩnh vực, học hàm/học vị) và xuất
trích dẫn toàn bộ công trình của một giảng viên.

## Điểm nhấn

- **Khoa thật từ kho nguồn** (lát cắt M): 10 mã khoa với tên chính thức theo ictu.edu.vn (5 khoa
  hiện tại CNTT, KT&CN, KT&QT, NT&TT, Khoa học liên ngành; các khoa tiền thân ĐTVT/ĐTTT, TĐH,
  HTTTKT, KHCB, TTĐPT còn ở bản ghi cũ). Bài báo gắn khoa theo facet `dept` (1.135/1.907 bài),
  giảng viên được gán khoa theo đa số công trình đã liên kết (222/400), "Ban Giám hiệu" không còn
  là đơn vị. Trang **Quản trị khoa** (`/don-vi/`, Phòng KH-CN) đổi tên/thêm bí danh có nhật ký;
  CLI `units list|rename|alias`, `people --assign-units`.
- **Bộ lọc mới ở Tra cứu**: Điểm quy đổi (0,5 / 0,75 / 1 / chưa xác định — điểm ghi ở nguồn theo
  loại ấn phẩm), Loại nơi công bố (tạp chí/hội thảo, quốc tế/trong nước), Chỉ mục đưa lên hàng
  lọc chính; cột Điểm và chip khoa ở kết quả; nút **Trích dẫn** ngay trên từng dòng.
- **Hồ sơ giảng viên** (lát cắt N): ảnh đại diện (ảnh riêng ở kho hoặc chữ cái đầu), tên kèm học
  hàm/học vị, chức vụ, khoa (ghi rõ khi suy từ đa số công trình), lĩnh vực, ORCID, Google
  Scholar; **Tải BibTeX (tất cả)** và **Sao chép APA (tất cả)** qua
  `GET /api/persons/{id}/citations?style=apa|ieee|bibtex`.
- Giao diện gọi đúng tên: "Khoa" thay cho "Đơn vị" ở mọi nơi chỉ bản ghi khoa.

## Nâng cấp từ 0.6.1

Migration `0020_units_from_source.sql` (bảng `work_unit`, `person.position`, `person.unit_source`,
seed 10 khoa, tắt BGH) và `0021_person_avatar_field.sql` (`person.avatar_url`, `person.field`) —
`deploy/upgrade.sh v0.7.0` tự áp. Sau khi lên, chạy một lần trên máy chủ (user `deploy`):

```bash
cd /opt/ictu-cris && docker compose exec web python -m cris sync            # quét thêm facet dept của bài báo
docker compose exec web python -m cris normalize --redo --doc-type bai_bao   # ghi work_unit từ depts
docker compose exec web python -m cris people                                # ảnh, lĩnh vực, chức vụ
docker compose exec web python -m cris people --assign-units                 # gán khoa theo đa số công trình
```

Câu hỏi còn mở với Phòng KH-CN: có gộp công trình của khoa tiền thân vào khoa hiện tại trong
thống kê không; có quy đổi điểm từ chỉ mục Scopus/ISI hay chỉ dùng điểm ghi ở nguồn.
