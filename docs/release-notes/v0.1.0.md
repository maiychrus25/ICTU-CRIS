# ICTU-CRIS v0.1.0 — bản dự thi

Hệ thống thông tin nghiên cứu (CRIS) cho Trường CNTT&TT – ĐH Thái Nguyên: một nguồn sự
thật cho dữ liệu công bố khoa học, mỗi con số truy ngược được về bản ghi gốc; AI gợi ý,
người quyết; không có AI vẫn chạy đủ chức năng.

## Có gì trong bản này

- **Đồng bộ** toàn kho `repository.ictu.edu.vn` (8.034 bản ghi, 6 loại), giữ nguyên
  bản gốc theo phiên bản, đối soát số lượng, quét bù phân trang.
- **Chuẩn hoá và đối soát**: xuất xứ từng trường, nối tác giả theo ORCID rồi theo tên,
  nghi trùng theo DOI / tiêu đề / tiêu đề + sinh viên + khoá, gộp giữ bản gốc.
- **Giao diện** hàng đợi xác nhận tác giả, hàng đợi nghi trùng (so từng trường cạnh
  nhau), tra cứu, hồ sơ công bố giảng viên, chất lượng dữ liệu, trang `/ve`.
- **AI**: đối chiếu đề tài trên tiêu đề + tóm tắt + từ khoá với bảng bốn khía cạnh;
  gợi ý xếp hạng cho hai hàng đợi; trục chủ đề từ gom cụm từ khoá. Mô hình
  `paraphrase-multilingual-MiniLM-L12-v2` ONNX 118 MB chạy CPU, không cần khoá API;
  `CRIS_AI_PROVIDER=none` vẫn chạy với đường lui.
- **Hồ sơ nguồn mở**: Apache-2.0, SPDX từng tệp, NOTICE, chính sách thư viện có giấy
  phép từng gói, CHANGELOG, CONTRIBUTING, mẫu issue/PR, CI, hướng dẫn dịch từ mã nguồn.

## Cài đặt

```bash
docker compose up -d db
pip install -e ".[ai]"          # hoặc chỉ `-e .` nếu không bật AI
python -m cris migrate && python -m cris seed
python -m cris sync && python -m cris people && python -m cris normalize \
  && python -m cris link && python -m cris dedup
python -m cris ai download && CRIS_AI_PROVIDER=local python -m cris ai embed
python -m cris serve
```

Chi tiết: `BUILDING.md`. Tài liệu AI: `docs/ai.md`. Yêu cầu: `docs/BRD.md`, `docs/SRS.md`.
