# ICTU-CRIS visual identity

ICTU-CRIS uses a restrained blue-tinted neutral canvas and one deep-blue action color to communicate institutional trust. Green, amber, and red are reserved for business states. Dark mode preserves the same hierarchy and contrast.

Pages use a fixed navigation shell, a compact header, and content up to 1440px. Tables remain tables; cards are reserved for grouped summaries or a single identity block. Controls expose visible labels, keyboard focus, loading, empty, and error states.

Profile imagery is circular, fixed-size, and paired with a text initial fallback so missing remote images never collapse the layout. Search filters wrap into responsive grids without page-level horizontal overflow at 390px, 768px, and desktop widths.
